# Précisions de lore validées (réponses de l'auteur)

Ces points complètent les documents d'origine (PDF V.11, CSV, XLSX) là où ils laissaient des zones d'ombre.

| Sujet | Décision |
|---|---|
| Gouvernance du Nouveau Régime | 7 doyens officiels ; Néo donne les vrais ordres dans l'ombre à Zeus et à la Force d'Autorité. |
| Orbitrail | Consortium public-privé : le régime tient les gares, des corpos exploitent les lignes, les contrôles sont délégués à la F.A. |
| Ogénite / genotite | Minerai radioactif naturel, présent dans le sol et l'eau ; il a éveillé des mutations et dérègle le climat. |
| Les 16 pierres réunies | Pouvoir absolu au prix fort : le détenteur peut remodeler le monde, mais l'ogénite le consume peu à peu. |
| ManaCorp (propagande + Marché Noir) | Double vie connue des autorités et tolérée (utile au régime). Ce n'est pas un secret pour l'État. |
| Fallen (implant explosif) | Fabriqué par Gamma Lab ; retrait possible mais coûteux (service majeur). |
| Statut d'un géno-porteur | Déclaration obligatoire, fichage, restrictions de métiers ; les non-déclarés sont traqués. |
| Omega Force | Géno-porteurs adoptés depuis l'enfance ou la naissance ; ils infiltrent les factions recherchées pour les neutraliser plus facilement. |
