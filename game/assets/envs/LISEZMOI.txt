IMAGES DES VILLES

Dépose ici une image par ville. Le nom du fichier est l'identifiant de l'État (colonne de gauche) + .jpg / .png / .webp
Exemple : mitropa.jpg pour Berlin.
Variantes facultatives selon l'heure : mitropa_night.jpg, mitropa_dusk.jpg, mitropa_day.jpg
Format conseillé : paysage, 1600 x 500 px (bandeau large). Elles seront réduites automatiquement.
Puis lance : python3 game/tools/build_envs.py game/assets/envs   puis   python3 game/build.py
Une ville sans image garde son décor vectoriel.
